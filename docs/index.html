Features

Everything you need to run a modern event bar

From QR code entry to pickup notification — every step is digital, fast, and frictionless.

📱

QR Code Entry

Customers scan a station-specific QR code and instantly access the menu. No app download, no sign-up friction.

🍸

Custom Drink Builder

Spirit + Mixer + Cup Option. Customers build exactly what they want with a visual, tap-friendly interface.

⚡

Real-Time Queue

Live order status via WebSocket. Customers know exactly where they are in the queue — no guessing, no hovering.

📊

Vendor Dashboard

Tablet-friendly interface for managing incoming orders. One-tap state transitions, availability toggles, and queue visibility.

💬

WhatsApp Notifications

Optional order updates via WhatsApp. Customers get notified when their drink is confirmed, ready, and collected.

🔒

Idempotent Payments

Duplicate-safe payment processing with idempotency keys. Network retries and double-taps are handled gracefully.

📡

Offline Support

PWA with service worker for graceful offline handling. The app recovers automatically when connectivity returns.

🌙

Dark/Light Theme

Automatic theme detection with manual toggle. Readable in bright outdoor festivals and dark indoor venues.

📈

Full Observability

OpenTelemetry traces, logs, and metrics piped to Elasticsearch + Kibana for real-time operational insight.

How It Works

From scan to sip in minutes

The entire order lifecycle is digital, transparent, and fast.

Scan QR Code

Customer scans the station QR code with their phone camera. The menu opens instantly in the browser.

Build Your Order

Choose a custom drink (spirit + mixer + cup) or grab a pre-made item. Add to cart.

Pay & Join Queue

Complete payment and receive a queue position. Your order enters the preparation queue immediately.

Track in Real-Time

Watch your order move through PREPARING → READY via live WebSocket updates or WhatsApp notifications.

Collect Your Drink

When notified, head to the pickup point. Show your order number and collect within the pickup window.

Order Lifecycle

Strict state management you can trust

Every state transition is persisted, timestamped, and pushed in real-time.

DRAFT → AWAITING_PAYMENT → PAID → PREPARING → READY → COLLECTED │ │ └──── CANCELLED ◀──────────┘ EXPIRED (pickup window exceeded) • Orders remain in DRAFT until checkout • Payment confirmation assigns a queue position • Only paid orders enter the preparation queue • All transitions pushed via WebSocket within 1 second • Full audit trail in order_state_history table
